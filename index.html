邀请奖励

基础规则不变：你邀请的 1 个人首次签到成功，你（邀请人）得 +20 分；被邀请人当天按正常签到得 10 分。在此之上，邀请人数达到档位后，你的全部积分（签到积分 + 邀请积分）按比例加成，得到有效积分——分奖金时按有效积分算。加成追溯生效：档位一到，之前已经攒下的积分也一起放大。

邀请人数全部积分加成有效积分倍数说明
1 – 9 人无加成× 1.0每邀请 1 人首次签到 +20 分，仅此而已。
10 – 19 人+20%× 1.2全部积分 ×1.2，含此前已攒的签到与邀请积分。
20 – 49 人+30%× 1.3全部积分 ×1.3，追溯生效。
50 人以上+50%× 1.5全部积分 ×1.5，最高档。

加成只看邀请人自己的邀请人数，按其全部积分计算；被邀请人的积分不因邀请人的档位变化。档位以链上记录的成功邀请人数为准。

示例一 · 邀请 10 人，进 +20% 档

签到 22 天得 220 分，邀请 10 人得 10 × 20 = 200 分，基础积分合计 420 分。达到 10 人档后，全部积分 +20%：

420 × 1.2 = 504 分有效积分
示例二 · 邀请 50 人，进 +50% 档

签到 22 天得 220 分，邀请 50 人得 50 × 20 = 1,000 分，基础积分合计 1,220 分。达到 50 人档后，全部积分 +50%：

1,220 × 1.5 = 1,830 分有效积分

每个被邀请人只算一次

邀请奖励只在被邀请人第一次签到时产生，同一个被邀请人之后每天再签到，都不会再给邀请人加分。换个链接、换个入口重复算也不行，以链上首次签到记录为准。

邀请人资格

邀请人必须是持有 Agent ID、且自己已经签到过的人。还没签过到就发邀请链接，邀请奖励不计；先完成自己的第一次签到，再去邀请别人。

不能自邀

用自己的地址邀请自己不算数，也不要用多个地址互相邀请刷分。Agent ID 一人一个、不可转让，自邀和刷量一经认定，相关邀请积分作废，处理口径与上方资格红线一致。

分奖金按有效积分

若项目获奖，用户池按有效积分（加成后）的比例分配：你的份额 = 用户池 ×（你的有效积分 ÷ 全网有效积分总和）。下方计算器也是按有效积分测算的。

用户池怎么分

个人可领金额 = 用户池总额 ×（你的有效积分 ÷ 全部有效积分）。有效积分 = 基础积分（签到 + 邀请）按你的邀请档位加成后的积分，档位规则见上方「邀请奖励」。只有投稿期内的签到计入；同一人多地址、批量注册等违规行为一经主办方或项目方认定，相关积分作废。

时间线

主办方在公示期结束后 14 个工作日内把奖金发到项目方提交的收款地址。奖金实际到账后，项目方把用户池份额注入已部署的分发合约并在本页公布领取开启时间；领取期为 90 天，期内由用户自行发起领取，逾期未领不再处理。

Agent ID 说明与合约配置

签到资格只看一件事：你的地址在 Agent ID 合约里的 balanceOf 是否大于 0。不查你的其他资产，不读取与签到无关的信息。

什么是 Agent ID

  • 给 AI Agent 使用的链上身份凭证，形式为一个 .ai 域名，绑定在你的钱包地址上。
  • 在官方 App 内领取：钱包首页的 Agent ID 入口按指引操作即可，每人限领 一个。
  • 不可转让：无法买卖或转给他人，换地址等于换身份，签到积分跟随持有地址。
  • 本项目用它做签到门禁：一人一 ID，天然限制批量小号刷积分。
  • 领取或使用中遇到要你交出私钥、助记词的页面，立即关闭——官方流程不会索要这些。

风险提示与规则

参与前请先读完

  • 获奖不确定：本项目正在参加 Agent ID 黑客松，能否获奖、获得第几名由主办方决定。未获奖时没有任何奖金可分，签到积分随之没有对应分配。
  • 金额不确定：即使获奖，可领金额还取决于奖金档位、参与总人数与总积分，人多时每人金额会明显变小（见上方示例）。页面上的示例数字均为假设测算。
  • 积分不是资产：积分只用于计算分配比例，不能转让、不能交易、没有价格，也不能在投稿期外使用。
  • Gas 自担：签到和领取都是链上交易，需要你自己支付网络 Gas；交易一旦上链不可撤销，请在钱包弹窗里核对合约地址与金额后再确认。
  • 防冒充：本站不会私信你、不会建群收费、不会让你把币转到任何“登记地址”。只认本页公布的合约地址，其余均为冒充。
  • 资格红线：批量注册、多地址刷量等行为违反主办方规则，可能导致项目被取消资格、所有人积分作废，请勿尝试。
签到必须用币安 Agent 钱包吗？普通钱包为什么签不了？

是的，必须用持有 Agent ID 的那个地址签到，而 Agent ID 是领在币安 Agent 钱包地址上的，所以要用币安 Agent 钱包那个地址来签。签到合约会检查你地址在 Agent ID 合约里的 balanceOf：普通钱包地址里没有 Agent ID，balanceOf 为 0，合约会直接拒绝，交易失败——这不是网站坏了，是资格不满足。

请注意：不要在任何网站上扫码登录 Agent 钱包，也不要输入配对码，本站不会让你这样做。正确的签到方式只有两种：1）在币安 App 内置浏览器里打开本网站，用持有 Agent ID 的钱包连接签到；2）通过你自己的 AI 代理，从你的 Agent 钱包地址调用签到合约，再由你在币安 App 里确认交易。

签到积分具体怎么算？

以 UTC 日期为界，每天成功签到 1 次得 10 分，每天上限 10 分。投稿期为 2026-11-18 00:00 UTC 至 2026-12-09 08:00 UTC，共 22 个可签到日期，满勤 220 分。邀请他人首次签到，每邀请 1 人 +20 分；邀请满 10 人起，你的全部积分按档位加成（10–19 人 +20%、20–49 人 +30%、50 人以上 +50%，追溯生效），加成后为有效积分，分奖金按有效积分算。投稿期外的签到（若合约保留该功能）不计入本次分配。

没获奖的话，我的积分怎么办？

没有获奖就没有奖金池，积分不产生分配，会在本页明确公告结果。签到记录仍可在链上查询，但积分本身不能兑换任何东西。

奖金什么时候能领、怎么领？

顺序是：主办方公布结果 → 奖金在公示期结束后 14 个工作日内发到项目方收款地址 → 项目方把其中 50% 注入已部署的分发合约并在本页公布领取开启时间 → 你使用投稿期内签到过的同一地址，在 90 天领取期内自行发起领取，逾期未领不再处理。整个过程没有人工转账，也不需要你提供任何账户信息。

我换了钱包地址，积分能合并吗？

不能。Agent ID 不可转让，积分绑定签到时使用的地址。领取时必须使用投稿期内签到过的同一地址，请妥善保管该钱包。

这个网站会保存我的什么信息？

不会。本站是静态页面：不设账户、不保存登录状态、不收集私钥或助记词。你的签到记录只存在于链上合约里，页面只是读取并展示它。
