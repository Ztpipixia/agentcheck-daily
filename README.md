# AgentCheck Daily

Daily check-in dApp for Binance Agent ID holders — entry for the Binance Agent ID Hackathon (Nov–Dec 2026).

- Live site: https://ztpipixia.github.io/agentcheck-daily/
- Check-in contract (BSC): `0x423D4cce9A6B428f92dD974cC0bF490F24ceD824`
- Prize distributor (BSC): `0x95A44489A5D0a14dE23E112652412c4535c8c46b`
- Agent ID contract (BSC): `0x60b9262456de011f7d15a54cdd8c48baaa8b022f`

Hold an Agent ID, check in once per UTC day, earn 10 points. Invite others: +20 points per first check-in, with tier bonuses on all your points at 10/20/50 invites (+20%/+30%/+50%). If the project wins a hackathon prize, 50% is shared pro-rata by effective points; claim it yourself within 90 days. Nothing is guaranteed.
